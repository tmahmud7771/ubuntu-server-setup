#  Ubuntu Zsh Setup Script

This project provides an automated script to set up a modern Zsh environment on Ubuntu/Debian systems with Oh My Zsh, autosuggestions, and syntax highlighting.

---

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/tmahmud7771/ubuntu-server-setup
cd ubuntu-server-setup
````



### 2. Give Execute Permission

```bash
chmod +x setup.sh
```

---

### 3. Run the Script

```bash
./setup.sh
```

---

## What This Installs

* Zsh shell
* Oh My Zsh framework
* Zsh Autosuggestions plugin
* Zsh Syntax Highlighting plugin
* Sets Zsh as default shell

---

## After Installation

Restart your terminal or run:

```bash
source ~/.zshrc
```

---

##  Requirements

* Ubuntu / Debian-based Linux
* sudo access
* Internet connection
