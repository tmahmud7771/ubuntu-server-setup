# Ubuntu Dev Zsh Setup (Ultimate)

A fully automated setup script to transform a fresh Ubuntu/Debian system into a modern developer terminal environment.

Includes:
- Zsh
- Oh My Zsh
- Autosuggestions
- Syntax Highlighting
- Powerlevel10k theme
- Clean dev-ready `.zshrc`

---

## One-Line Install (Recommended)

```bash
curl -fsSL https://raw.githubusercontent.com/<your-username>/zsh-setup/main/setup.sh | bash
````

---

## Manual Install

### 1. Clone Repository

```bash
git clone https://github.com/<your-username>/zsh-setup.git
cd zsh-setup
```

---

### 2. Make Script Executable

```bash
chmod +x setup.sh
```

---

### 3. Run Setup

```bash
./setup.sh
```

---

## What This Setup Does

### Core System

* Updates Ubuntu packages
* Installs `zsh`, `git`, `curl`, `wget`

### Shell Framework

* Installs Oh My Zsh
  [https://github.com/ohmyzsh/ohmyzsh](https://github.com/ohmyzsh/ohmyzsh)

### Plugins

* Autosuggestions
  [https://github.com/zsh-users/zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions)
* Syntax Highlighting
  [https://github.com/zsh-users/zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting)

### Theme

* Powerlevel10k
  [https://github.com/romkatv/powerlevel10k](https://github.com/romkatv/powerlevel10k)

---

## Post Install Steps

### 1. Reload shell configuration

```bash
source ~/.zshrc
```

---

### 2. Configure Powerlevel10k

```bash
p10k configure
```
